### 🧬 Research & Engineering Deep Dive

<details>
  <summary><b>🔬 01. Genetic Algorithms in Convolutional Neural Networks</b> <i>(Click to expand)</i></summary>
  <br/>
  <blockquote>
    <p>Standard deep neural networks often suffer from high computational overhead and suboptimal hyperparameter combinations when segmenting complex biomedical images. My implementation combines evolutionary heuristic search (selection, crossover, mutation) with deep convolutional layers to:</p>
    <ul>
      <li>Automatically discover optimal convolutional kernel configurations.</li>
      <li>Filter out redundant multi-spectral MRI noise before classification.</li>
      <li>Achieve higher F1-scores on challenging heterogeneous tumor tissue boundaries.</li>
    </ul>
  </blockquote>
</details>

<details>
  <summary><b>🖐️ 02. Real-Time Spatial Hand Tracking with OpenCV</b> <i>(Click to expand)</i></summary>
  <br/>
  <blockquote>
    <p>By transforming raw video frames into HSV / Euclidean landmark coordinates, the gesture controller calculates the dynamic vector distance between the thumb tip and index fingertip. This distance is then mapped via continuous linear interpolation onto the OS system brightness slider in real time with smoothing filters to eliminate jitter.</p>
  </blockquote>
</details>

<details>
  <summary><b>⚡ 03. Asynchronous Django & Clean ORM Architecture</b> <i>(Click to expand)</i></summary>
  <br/>
  <blockquote>
    <p>Demonstrated modern web performance techniques by decoupling HTTP request cycles from user interface rendering. Utilizing asynchronous JavaScript (AJAX) coupled with Django's Model-View-Template architecture, database records are validated, persisted, and updated in real-time with sub-millisecond response latency.</p>
  </blockquote>
</details>
